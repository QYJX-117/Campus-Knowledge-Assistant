# 河海智答：课程验收与演示说明

## 项目定位

“河海智答”是面向河海大学师生的校园知识问答工具。项目保留课程要求的 React、Ant Design、JWT、RAG、FAISS、SSE 与 Docker/Nginx 技术链路；后端采用 FastAPI 一体化实现，替代课程示例中的 Spring Boot + 独立 Python AI 服务，减少课程演示时的进程数量与部署复杂度。

## 课程要求映射

| 课程模块 | 项目实现 | 验收入口 |
| --- | --- | --- |
| 注册、登录、退出 | JWT 登录，密码哈希存储，账号状态校验 | `/login` |
| 角色权限 | ADMIN/STUDENT 前后端双重校验，学生访问管理 API 返回 403 | `/admin`、`/chat` |
| 用户管理 | 搜索、角色切换、启用/停用 | `/admin/users` |
| 知识库管理 | TXT/MD/PDF/DOCX 校验、后台索引、状态轮询、重处理、删除 | `/admin/knowledge` |
| RAG 问答 | FAISS + BM25 + RRF，支持 dense/bm25/hybrid/HyDE/multi/full | `/admin/chat`、`/chat` |
| 流式输出 | POST SSE 流，支持停止生成 | 问答工作台 |
| 来源追溯 | 来源标题、片段、相关度展示，README/INDEX 与重复内容过滤 | 回答下方来源标签 |
| 历史记录 | 会话保存、切换、删除、Markdown 导出 | 问答工作台左侧 |
| 系统管理 | 统计卡片、7 天趋势、配置保存、知识库重建 | `/admin`、`/admin/settings` |
| 嵌入式组件 | Shadow DOM + UMD 单文件，`window.HHUChat.init()` | `dist-widget/widget.js` |

## 当前知识库说明

当前知识库按 `knowledge-base/` 下的 19 个业务分类组织（学校概况、图书馆、食堂、宿舍、校园卡、网络、医疗、体育、交通、邮寄、教务、资助、财务、安全、就业、心理、国际交流、招生、校园服务），共 20 篇文档、357 个索引块。另有启动时写入的“河海大学校园服务指南（示例）”用于校训、图书馆、校园卡、奖学金等问题的稳定复现。`knowledge-base/INDEX.md` 记录整理来源，但索引文件本身不参与 RAG，避免链接目录污染回答来源。

当校园文档需要更新时，将 Markdown 文件放入 `knowledge-base/` 的对应分类目录，在系统配置页执行“重建知识库索引”即可接入，无需修改问答代码。

## 5 分钟演示顺序

1. 使用 `admin@campus.example / admin123` 登录，展示四张统计卡片和趋势图。
2. 在知识库管理页上传一份 TXT 或 Markdown，展示“处理中 → 已完成”。
3. 在问答工作台选择“混合检索”，提问“河海大学的校训是什么？”，展示流式回答和来源。
4. 切换到“关键词检索”或“向量检索”再次提问，说明检索策略差异。
5. 提问“今天天气怎么样？”，展示“知识库暂无相关内容”。
6. 展示历史会话切换、复制、Markdown 导出和删除确认。
7. 使用学生账号登录，展示无管理菜单，并说明学生访问文档 API 会返回 403。

## 离线与外部服务保护

- 本地 BGE 模型可用时使用真实语义向量；模型未缓存且无法联网时自动使用 512 维中文哈希向量，保证系统可启动。
- LLM 请求设置超时与重试（`LLM_TIMEOUT_SECONDS` / `LLM_MAX_RETRIES`）；外部模型不可用时，系统从检索片段生成带来源编号的抽取式回答。
- 正式效果评估仍建议配置可用的 DeepSeek 或兼容 OpenAI API，并使用真实校园文档重新构建索引。
