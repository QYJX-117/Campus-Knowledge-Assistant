# 14 — 就业发展

> 数据来源：河海大学学生就业指导中心 (job.hhu.edu.cn)、各学院学工办
> 更新周期：每学期核实一次（招聘信息和政策变化频繁）
> 最近更新：2026-07-18

---

## 14.1 管理机构与信息渠道

河海大学学生就业指导中心统筹全校毕业生就业工作，是发布招聘信息、就业政策的核心平台。各学院设就业专员（辅导员）对接学生就业事务。就业信息网 **job.hhu.edu.cn** 是学生获取校招信息、上传就业数据、办理就业手续的主渠道，建议从入学起就关注该网站和对应微信公众号。学校强调毕业生要把握好秋招（9—11月）和春招（3—5月）两个黄金窗口期。

- [x] 就业指导中心官网：**job.hhu.edu.cn**
- [x] 微信公众号：**河海大学就业**
- [x] 办公地址：西康路/江宁校区均有就业指导中心办公室
- [x] 各学院就业联系人：各学院学工办辅导员/就业专员
- [x] 招聘黄金期：**秋招 9—11 月 / 春招 3—5 月**

## 14.2 招聘信息获取

- [x] 校内平台：就业信息网 ☑ / 微信公众号 ☑ / 毕业生微信群/QQ群 ☑ / 各学院就业群 ☑
- [x] 校外平台：国家大学生就业服务平台（24365）☑ / 智联招聘 / 前程无忧 / 各用人单位官网
- [x] 校园招聘会：每年秋招和春招举办大型双选会和专场宣讲会

## 14.3 三方协议（就业协议书）

三方协议全称为《全国普通高等学校毕业生就业协议书》，签约方为毕业生、用人单位和学校，是学校派遣毕业生、办理户口迁移和档案转递的重要依据。签约须按规范流程：**用人单位先盖章 → 再到学校就业指导中心签证盖章**，不可自行先填。签完后须登录就业信息网上传就业信息。如需换单位，须原公司开具**解约函**并退回旧三方，持解约函和旧三方到辅导员处领取新空白协议。

- [x] 三方协议全称：全国普通高等学校毕业生就业协议书
- [x] 签约方：毕业生 + 用人单位 + 学校
- [x] 签约流程：用人单位盖章 → 就业指导中心签证盖章 → 上传就业信息网
- [x] 专业名称须与教务处一致，不可简写
- [x] 试用期：一般 3 个月，最长不超 6 个月
- [x] 违约金：建议最低，通常不超 **5,000 元**
- [x] 解约换单位：须原公司开具解约函 + 退回旧三方 → 领新空白协议

## 14.4 档案与户口

毕业生离校前档案转递依据三方协议或就业去向进行。档案通常寄送至用人单位（有人事接收权）、单位所在地人才市场、或生源地人社局/教育局。户口在学校集体户口的毕业生，须凭毕业去向材料到保卫处办理户口迁出（详见 13-security.md）。

- [x] 档案去向：用人单位 / 人才市场 / 生源地人社局
- [x] 户口迁出：凭毕业去向材料到保卫处办理
- [x] 档案查询：毕业后可在就业信息网查询寄送状态

## 14.5 就业指导服务

学校就业指导中心和各学院定期举办简历制作、模拟面试、职业生涯规划等培训活动。学生可通过就业信息网或辅导员预约一对一咨询。

- [x] 就业指导活动：简历指导 / 模拟面试 / 生涯规划 / 名企参访
- [x] 一对一咨询：通过就业信息网或辅导员预约

## 14.6 毕业去向

毕业生去向类型包括：签就业协议（三方协议）、签劳动合同、国内升学（保研/考研）、出国出境深造、自主创业、自由职业、应征入伍等。所有去向均须在就业信息网登记确认。

- [x] 去向类型：签协议就业 / 签合同就业 / 升学 / 出国 / 创业 / 入伍
- [x] 信息登记：所有去向须在就业信息网上确认
