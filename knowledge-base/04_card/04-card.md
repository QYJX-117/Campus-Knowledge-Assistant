## 4.1 校园卡概述

河海大学校园卡是师生在校内的核心身份凭证和支付工具，集消费、门禁、借阅、考勤、身份证明等功能于一体。校园卡由信息化建设与管理处（网信办）统一管理，新生入学时由各学院统一发放。校园卡同时支持实体卡和虚拟卡两种形态——实体卡刷卡使用，虚拟卡通过微信公众号绑定后可扫码支付。校园卡网站为 **ecard.hhu.edu.cn**，可用于网上挂失、余额查询、消费账单查询等操作。咨询电话：**400-837-1915** / **025-83787582**。

- [x] 校园卡全称：**河海大学校园一卡通**
- [x] 发卡机构：信息化建设与管理处（网信办）
- [x] 校园卡功能：消费 ☑ / 门禁 ☑ / 图书借阅 ☑ / 考勤 ☑ / 身份证明 ☑ / 洗澡热水（部分宿舍） ☑ / 电控缴费 ☑ / 医疗挂号 ☑ / 打印复印 ☑

## 4.2 办卡与补办

新生入学时由学院统一发放校园卡，无需单独办理。如校园卡遗失或损坏，可通过自助补卡机或人工窗口补办。自助补卡机刷身份证或输入学号+消费密码即可补卡，工本费 **20 元**，直接从卡内余额扣除（余额须大于 20 元）。补卡后老卡自动作废。人工窗口补办须携带本人身份证件。

- [x] 新生如何领取校园卡：入学时由学院统一发放
- [x] 补办费用：**20 元**（从卡内余额扣除）
- [x] 补办所需材料：身份证或学生证，需输入消费密码

## 4.3 充值

校园卡支持线上和线下两种充值方式。推荐使用微信公众号线上充值，方便快捷。线下可在各食堂圈存机操作。圈存服务时间为每日 **0:30—21:30**（因银行对账限制）。充值后资金直接进入校园卡账户，无需额外"领款"步骤（部分老式圈存机可能需到领款机贴卡）。

- [x] 充值方式：圈存机 ☑ / 微信 ☑ / 支付宝 ☑ / 中国银行 APP ☑ / 现金（仅人工窗口） □
- [x] 线上充值入口：微信公众号 **"河海大学网信办"** → "网信服务" → "自助校园卡" → "卡片充值"；或微信公众号 **"河海大学财务处"** → "财务服务" → "自助校园卡"
- [x] 校园卡网站：**ecard.hhu.edu.cn**（网上挂失、查询、充值）

## 4.4 挂失与解挂

发现校园卡遗失应**立即挂失**，防止卡内余额被盗刷。挂失后如果找回卡片可通过相同渠道解挂，恢复使用。

- [x] 挂失方式：
  1. 微信公众号"河海大学网信办" → "自助校园卡" → 挂失（推荐，最快捷）
  2. 各校区圈存机自助挂失（24 小时可用）
  3. 登录 ecard.hhu.edu.cn 网上挂失
  4. 前往一卡通人工窗口挂失
- [x] 解挂方式：同上渠道，选择"解挂"操作（须携带校园卡和身份证到人工窗口或通过自助设备）
- [x] 挂失后补办：挂失后余额被冻结，补办新卡后余额自动转入新卡

## 4.5 使用限制

校园卡设有消费限额保障资金安全。默认单日累计消费限额为 **50 元**，超出需输入消费密码。可通过自助设备或人工窗口修改限额。校园卡在有效期内持续有效（一般至毕业离校），毕业生离校时卡内余额可退还至绑定的建行卡。

- [x] 单日消费限额：默认 **50 元**（超出需输密码）
- [x] 修改限额方式：圈存机自助修改 / 人工窗口申请
- [x] 校园卡有效期：在校期间持续有效，毕业后注销
- [x] 初始密码：**身份证后六位**（末位为字母则前推一位），无身份证则为 **888888**

## 4.6 虚拟校园卡

河海大学已全面支持虚拟校园卡，通过微信公众号绑定后即可使用手机扫码消费，无需携带实体卡。虚拟卡与实体卡共用同一账户余额。同时支持微信、支付宝、云闪付等聚合支付（需先完成虚拟卡认证绑定）。

- [x] 是否支持虚拟卡：是 ☑
- [x] 绑定方式：关注微信公众号 **"河海大学网信办"** → "网信服务" → "自助校园卡" → 输入学号+查询密码绑定
- [x] 虚拟卡功能：扫码支付、余额查询、卡片充值、消费账单、挂失/解挂、电费缴纳、校园网缴费
- [x] 聚合支付：支持微信/支付宝/云闪付（须先完成虚拟卡认证绑定）
