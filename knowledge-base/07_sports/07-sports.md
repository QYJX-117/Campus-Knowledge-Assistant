# 07 — 体育设施

> 数据来源：河海大学体育系 (tyb.hhu.edu.cn)、后勤管理处、学生社区分享
> 更新周期：每学期核实一次
> 最近更新：2026-07-18

---

## 7.1 江宁校区

江宁校区作为主校区，体育设施最为完备。东操场为大型综合田径场，新生开学典礼、运动会、体测均在此进行。西操场为足球场，邻近篮球场。文体中心内含室内羽毛球场、体育舞蹈和形体教室。游泳馆位于东操对面，内设乒乓球和飞镖设施。南门进门左手边为室外篮球场（多个全场），东操对面另有小型篮球场配健身设施。室外羽毛球、网球、排球场集中在东操旁边。

- [x] 田径场（东操场）：标准 400 米塑胶跑道 ☑，全天开放
- [x] 足球场（西操场）：人工草坪 ☑
- [x] 篮球场：南门旁（多片全场）+ 东操对面（2 个篮球架）
- [x] 游泳馆：东操对面，内含乒乓球/飞镖
- [x] 室内羽毛球场：文体中心内
- [x] 室外网球/排球/羽毛球场：东操旁
- [x] 健身设施：东操对面小篮球场旁

## 7.2 西康路校区

西康路校区（鼓楼本部）虽面积较小，但体育设施齐全，配备操场、足球场、游泳池、篮球场、网球场、排球场。由于校区位于市中心，部分设施与周边社区共享。

- [x] 田径场：有 ☑，塑胶跑道
- [x] 足球场：有 ☑
- [x] 游泳池：有 ☑（室外，夏季开放）
- [x] 篮球场：有 ☑
- [x] 网球场：有 ☑
- [x] 排球场：有 ☑

## 7.3 常州校区（金坛）

常州金坛校区为新建校区，体育设施为三校区最新。体育场馆群位于校园西南角，总建筑面积约 37,000 平方米，由体育场（~13,000 ㎡）、体育馆（~13,000 ㎡）、游泳馆（~11,000 ㎡）三栋独立建筑组成，设施标准为承接国内大型赛事设计。

- [x] 体育场：~13,000 ㎡，标准田径场 + 看台
- [x] 体育馆：~13,000 ㎡，含篮球/羽毛球/乒乓球等室内场地
- [x] 游泳馆：~11,000 ㎡，室内恒温泳池
- [x] 总建筑面积：~37,000 ㎡

## 7.4 体测（体质健康测试）

体测是本科生必修环节，每学年进行一次，一般在江宁校区东操场和体质测试中心进行。项目包括身高/体重、肺活量、50 米跑、坐位体前屈、立定跳远、引体向上（男）/仰卧起坐（女）、1000 米（男）/800 米（女）。体测成绩与体育课成绩和毕业挂钩。因病或残疾可申请免测（须提供三级甲等医院证明）。

- [x] 频率：每学年一次
- [x] 地点：江宁校区东操场 + 体质测试中心
- [x] 项目：身高体重/肺活量/50米/坐位体前屈/立定跳远/引体向上(男)仰卧起坐(女)/1000米(男)800米(女)
- [x] 免测条件：因病或残疾 + 三级甲等医院证明，经审批可免测
- [x] 体育课程免修：不可 ☑（体育课为必修，不可免修但可因伤病申请缓修）

## 7.5 场馆预约

体育场馆预约方式和开放时间因校区和场馆类型而异。体育课教学期间部分场馆优先保障教学使用，课余时间向师生开放。详细信息建议访问体育系官网 **tyb.hhu.edu.cn** 或关注体育系微信公众号。

- [x] 预约方式：详见 tyb.hhu.edu.cn 或体育系公众号
- [x] 开放时间：教学时段优先保障课程，课余向师生开放
- [x] 收费标准：多数室外场地免费，室内场地（游泳馆/羽毛球馆等）可能收取适当费用

## 7.6 运动会

河海大学每年举办校田径运动会（一般为 10 月下旬，如 2025 年为 10 月 24-25 日），此外各学院也举办院内运动会和各类体育比赛。运动会期间停课，缺课不补。

- [x] 校田径运动会：每年 ~10 月下旬
- [x] 运动会期间：停课，缺课不补
- [x] 体育系官网：**tyb.hhu.edu.cn**
