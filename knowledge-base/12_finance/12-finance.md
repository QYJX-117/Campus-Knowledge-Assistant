# 12 — 财务缴费

> 更新周期：每学年核实一次
> 最近更新：2026-07-18

## 12.1 缴费平台与方式

河海大学学费和住宿费主要通过**"河海大学校园统一支付平台"（综合缴费平台）**缴纳，支持微信、支付宝、建行 APP 三种在线支付方式，无手续费。除线上缴费外，老生还可通过学校统一发放的**中国建设银行卡**进行批量代扣——在指定日期前足额存入即可自动扣款，代扣一般在开学前后和每周二执行。缴费有疑问联系计财处收费管理科：**025-83786338** / **025-83787143**。

**安全提醒**：除以上官方渠道外，学校未公布任何其他缴费途径，请勿轻信私人发送的缴费二维码或链接。

- [x] 统一支付平台：**http://cwcwx.hhu.edu.cn/xysf**
- [x] 手机端：微信公众号 **"河海大学计财处"** → "财务应用" → "综合缴费平台"
- [x] 电脑端：河海大学官网 → "校园生活" → "校园服务" → "综合缴费平台"
- [x] 登录账号：**学号**，初始密码：**Hhu@ + 身份证后六位**（2025 级）/ **身份证后六位**（往年版）
- [x] 首次登录须修改密码
- [x] 支付方式：微信 ☑ / 支付宝 ☑ / 建行 APP ☑
- [x] 收款方：**河海大学**（认准官方）
- [x] 计财处官网：**https://cwc.hhu.edu.cn**

## 12.2 银行卡代扣

学校统一办理中国建设银行卡（随录取通知书寄送）。代扣期间综合缴费平台学杂费功能暂时关闭，代扣结束后恢复。

- [x] 代扣银行卡：**中国建设银行卡**（学校统一发放）
- [x] 代扣时间：开学前后首次批量 + 之后**每周二**例行
- [x] 操作：指定日期前足额存入即可
- [x] 助学贷款学生注意：批扣期间勿存生活费以免误扣
- [x] 线上补缴：通常**周六、日及节假日**开通

## 12.3 收费标准

| 费用 | 金额 | 说明 |
|------|:----:|------|
| 本科生学费 | 5,200—5,720 元/年 | 按专业不同 |
| 学术硕士学费 | 8,000 元/年 | 全日制 |
| 专业硕士学费 | ~10,000 元/年 | 各专业有差异 |
| 博士学费 | 10,000—25,000 元/年 | 按专业/类型 |
| 住宿费 | 750—1,500 元/年 | 西康路旧舍 750-1,400，其余 ~1,500 |

## 12.4 毕业生财务事项

离校前须缴清所有学杂费。校园卡余额和住宿费退费均退回建行卡，**收到所有退费前勿注销该卡**。

- [x] 离校前：缴清所有学杂费
- [x] 退费：校园卡余额/住宿费 → 退回建行卡
- [x] 银行卡丢失/更换：综合缴费平台 → "我的" → "银行卡维护" 更新

## 12.5 常见问题

**Q: 缴费后显示未到账？** 先确认银行卡是否已扣款，已扣款勿重复缴费，系统会自动恢复。超 24 小时未到账联系计财处。

**Q: 可以分期吗？** 困难学生可申请助学贷款（详见 11-aid.md），或咨询缓缴政策。

**Q: 如何获电子发票？** 综合缴费平台"缴费记录"可下载。纸质发票到计财处收费管理科办理。
