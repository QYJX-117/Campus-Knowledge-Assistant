# 09 — 快递邮政

> 数据来源：河海大学后勤管理处、菜鸟驿站、学生社区分享
> 更新周期：每学期核实一次（快递点位置可能变动）
> 最近更新：2026-07-18

---

## 9.1 江宁校区

江宁校区校内设有菜鸟驿站（8 舍隔壁），是主要快递收发点，营业时间 8:00—20:00，支持中通、顺丰、京东、邮政等主流快递寄取。部分快递公司有独立取件点——韵达在南门外白色集装箱、京东/亚马逊在南门、申通在骏园广场。最终取件地点请以收到的短信取件码为准，快递点位偶尔调整。

邮寄地址：**江苏省南京市江宁区佛城西路 8 号 河海大学江宁校区**（邮编 211100）

- [x] 校内菜鸟驿站：8 舍隔壁，8:00—20:00，支持中通/顺丰/京东/邮政寄取
- [x] 学校收发室：EMS
- [x] 南门：京东、亚马逊、当当
- [x] 南门外：韵达（过马路斜对面白色集装箱）
- [x] 骏园联通：韵达备用点
- [x] 骏园广场：申通
- [x] 六韬楼洗衣房背后：圆通

## 9.2 西康路校区

西康路校区快递服务集中在网球场旁的菜鸟驿站。近期有变动：体育场旁边老菜鸟驿站取申通快递，新疆馆外卖柜北侧新菜鸟驿站取邮政和韵达快递。EMS 通过学校收发室收发。

邮寄地址：**江苏省南京市鼓楼区西康路 1 号 河海大学校内**（邮编 210098）

- [x] 菜鸟驿站：网球场旁（老站取申通 / 新站取邮政+韵达）
- [x] 学校收发室：EMS
- [x] 主流快递均可达

## 9.3 常州校区（金坛）

校内菜鸟驿站位于西区 32 号楼，营业时间 9:00—20:00，支持菜鸟、京东、邮政等主流快递。**特别提醒：邮政快递单独在校外**，需从东门出去到河海园小区门口取件，距离较远。

邮寄地址：**江苏省常州市金坛区河海大道 1915 号 河海大学常州校区**（邮编 213200）

- [x] 菜鸟驿站：西区 32 号楼，9:00—20:00
- [x] 支持：菜鸟、京东、邮政、中通、圆通、韵达、极兔
- [x] **邮政特殊**：校外东门河海园小区门口取件，距离远
- [x] 寄件：通过菜鸟驿站寄出

## 9.4 寄件指南

寄件到校推荐使用菜鸟驿站支持的公司（中通、顺丰、京东、邮政），免去校外取件麻烦。毕业季（6 月）学校集中受理行李托运，宿舍区设临时托运点，详见后勤管理处通知（https://hqglc.hhu.edu.cn）。大件行李建议顺丰或德邦。

- [x] 推荐公司：中通、顺丰、京东、邮政
- [x] 毕业季托运：每年 6 月集中办理
- [x] 邮政平邮：通过收发室，慢但便宜

## 9.5 实用提示

1. 取快递须凭短信取件码（菜鸟驿站也支持淘宝/支付宝扫码）
2. 快递一般保留 3—5 天，超期可能退回
3. 大促期间（双11、618）快递点爆仓，建议错峰
4. 寄贵重物品建议顺丰保价
