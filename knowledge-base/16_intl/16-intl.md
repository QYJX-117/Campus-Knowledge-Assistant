## 16.1 管理机构

河海大学国际教育学院（网址 ie.hhu.edu.cn / hhis.hhu.edu.cn）成立于 2007 年，统筹实施来华留学教育、涉外培训、国际汉语教学与推广、学生校际交流项目。国际合作处（gjhzc.hhu.edu.cn）负责学校层面的国际合作事务，包括国家公派留学项目、创新型人才国际合作培养项目等。中非学院挂靠国际教育学院。

- [x] 国际教育学院：**ie.hhu.edu.cn** / **hhis.hhu.edu.cn**
- [x] 国际合作处：**gjhzc.hhu.edu.cn**
- [x] 地址：南京市鼓楼区西康路 1 号（邮编 210098）
- [x] 电话：+86 25 83787955
- [x] 邮箱：cie@hhu.edu.cn / admission@hhu.edu.cn

## 16.2 出国交换与联合培养

河海大学与美、英、法、俄、德、荷、澳、日及香港等国家和地区的 **70 多所大学**和科研机构建立了合作关系。主要项目类型包括中外联合培养（2+2、3+1+1、3+1+2 等模式，获中法双学位等项目）、国家留学基金委（CSC）创新型人才国际合作培养项目、以及寒暑期短期课程和交流访问。

- [x] 合作院校数量：**70+ 所**
- [x] 主要合作国家/地区：美、英、法、俄、德、荷、澳、日、香港等

### CSC 创新型人才国际合作培养项目

合作院校包括澳大利亚西澳大学（海洋科学）、马来西亚马来亚大学（可持续AI）、英国卡迪夫大学（卓越工程师）、新西兰奥克兰大学（水科学）、澳大利亚墨尔本大学（工程与信息技术）。选派类别涵盖博士研究生、联合培养博士/硕士、访问学者、博士后。

- [x] CSC 项目：每年多批次选拔，详见 gjhzc.hhu.edu.cn 通知

## 16.3 出国交流选拔条件

以中法工程师项目为例，基本要求包括必修课平均学分绩点在 **4.0 以上**（部分项目 3.5 以上）、国家大学英语四级 **425 分以上**（部分项目需雅思/托福/法语）、品德良好综合素质高、身体健康。具体条件因项目而异，以各项目选拔通知为准。

- [x] 绩点要求：一般 ≥ 3.5—4.0（视项目而定）
- [x] 外语要求：CET-4 ≥ 425 分（部分项目需雅思 6.0+ 或托福 80+）
- [x] 法语项目：须完成法语培训
- [x] 选拔流程：个人申请 → 学院推荐 → 学校评审 → 合作院校录取

## 16.4 来华留学（招收国际学生）

河海大学是国家首批授权可授予外国留学生博士、硕士、学士学位的高校，已为 100 多个国家和地区培养了数千名各类人才。2025/2026 学年有 62 个中文授课本科专业招收留学生。申请者须为非中国籍公民、身心健康、年龄 18-30 周岁、高中毕业或同等学历、HSK4 级及以上。

- [x] 本科专业数：62 个（中文授课）
- [x] 汉语要求：HSK4 级及以上
- [x] 申请系统：**admission.hhu.edu.cn**
- [x] 申请截止：每年约 **4 月 10 日**
- [x] 报名费：400 元
- [x] 本科学费：20,000 元/年

## 16.5 港澳台交流

河海大学与港澳台地区多所高校保持合作交流关系，包括学术互访、短期研修、联合培养等形式。港澳台事务办公室统筹相关业务，具体项目信息通过国际合作处网站发布。

- [x] 港澳台事务：国际合作处统一管理
- [x] 台湾高校交换：每学期开放申请，详见 gjhzc.hhu.edu.cn

## 16.6 外教与语言学习

国际教育学院开设有国际汉语教学项目。校园内定期有外籍教师和留学生交流活动，学生可通过国际教育学院组织的中外学生交流活动提升外语能力和跨文化交际能力。
