## 5.1 校园网 WiFi

### SSID 与连接方式

- [x] 校园网统一 WiFi 名称（SSID）：**Hohai University**（三校区统一，全校楼宇全覆盖）
- [x] 其他 WiFi 信号：
  - **eduroam**：全球教育漫游服务，外校来访用户免费接入；本校师生到其他联盟院校使用（账号格式：`学号@hhu.edu.cn`），南京校区非宿舍区覆盖
  - **CMCC-EDU**：常州校区保留的移动宽带信号（部分区域）
  - **HHUCAN**：中国移动热点（南京早期遗留，已基本停用）
- [x] 认证方式：**Portal 网页认证**（基于 Web 的强制门户）
- [x] 连接步骤：
  1. 搜索并连接 WiFi 信号 **Hohai University**，终端设置为自动获取 IP
  2. 打开浏览器访问任意网址（如 www.baidu.com），自动弹出认证页面
  3. 若未自动弹出，手动访问认证页面：**http://eportal.hhu.edu.cn** 或 **http://10.96.0.155**
  4. 输入用户名（学号）和密码（信息门户统一密码），选择服务通道，点击登录
- [x] 无感认证（推荐开启）：登录成功后在页面顶部开启"本机无感认证"开关，**30 天内**无需重复登录；可在自助服务系统 zfw.hhu.edu.cn 的「我的设备」中管理/取消
- [x] 下线方式：浏览器访问 **10.96.0.155**，点击「下线 Logout」

### 设备与时长限制

- [x] 同时在线设备数：**最多 3 台终端**同时在线

## 5.2 VPN 校外访问

- [x] VPN 类型：
  - **WebVPN**（推荐）：完全基于浏览器，无需安装客户端
  - **SSL VPN**：需通过 EasyConnect 客户端访问
- [x] VPN 地址：
  - **WebVPN**：**https://webvpn.hhu.edu.cn/**
  - **SSL VPN**：**https://vpn.hhu.edu.cn/**
- [x] WebVPN 使用方法：
  1. 浏览器访问 https://webvpn.hhu.edu.cn
  2. 选择「CAS统一身份认证登录」
  3. 输入学号/工号和信息门户密码登录
  4. 登录后点击资源链接（如中国知网等）即可直接访问校内资源
  5. 也可在搜索框中输入校内域名进行跳转
- [x] SSL VPN 客户端下载地址：**https://hhic.hhu.edu.cn/13537/list.htm**（各平台 EasyConnect 客户端）
- [x] 登录账号密码：**同校园网/信息门户**（统一身份认证）
- [x] 是否自动开通：**是**，教职工和全日制在校学生已**自动开通** VPN 服务，无需另行申请
- [x] 支持系统：**Windows** / **Mac** / **Linux** / **iOS** / **Android**
- [x] CARSI 校外访问（部分数据库免 VPN）：访问 https://ds.carsi.edu.cn/login/index.html → 搜索"河海大学" → 统一身份认证登录
- [x] 注意事项：VPN 服务器承载力有限，高峰期可能出现缓慢现象，建议错峰使用；校内通过校园网可直接访问资源，**无需使用 VPN**
