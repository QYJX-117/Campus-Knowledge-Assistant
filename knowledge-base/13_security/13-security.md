# 13 — 安全保卫

> 数据来源：河海大学保卫处 (bwc.hhu.edu.cn)、各校区派出所
> 更新周期：每学期核实一次

## 13.1 保卫处概况

保卫处（党委保卫部）是负责学校安全稳定工作的党务行政管理机构，统筹校园治安、消防、交通、户籍等安全保障工作。处长胡忠华，办公电话 **025-83786212**，邮箱 bwc@hhu.edu.cn。办公地址位于西康路校区学生区配电房二楼。保卫处 24 小时值班，校园发生任何安全事故均可随时联系。官网 **bwc.hhu.edu.cn** 发布最新安全通知和政策。校园报警电话：**025-83787110**（西康路/江宁通用）。

- [x] 保卫处全称：河海大学保卫处（党委保卫部）
- [x] 处长：胡忠华
- [x] 办公电话：**025-83786212**
- [x] 办公地址：西康路校区学生区配电房二楼
- [x] 官网：**bwc.hhu.edu.cn**
- [x] 报警电话：**025-83787110**

## 13.2 户籍管理

保卫处负责校内教职工和学生的集体户口、居民身份证管理。新生入学可将户口迁至学校集体户口（自愿办理）。毕业生离校前须到保卫处办理户口迁出手续。外来务工人员须办理暂住证和临时出入证。临时来校学习、进修、协作人员也须办理教学区通行证。

- [x] 集体户口：入学时自愿迁入，毕业前须迁出
- [x] 户口迁入流程：凭录取通知书到原籍派出所迁出 → 报到时交材料 → 保卫处统一办理
- [x] 户口迁出（毕业）：到保卫处领取户口迁移证
- [x] 身份证办理：凭学生证和户口页到辖区派出所办理
- [x] 户籍咨询：**025-83786212**

## 13.3 门禁管理

三校区均设有智能门禁系统。校内人员凭校园卡刷卡进入校园和宿舍楼。外来人员须登记并说明来访事由。教学区、图书馆、宿舍楼等均有独立门禁，须刷校园卡通过。夜间校园实行封闭管理，门卫 24 小时值班。

- [x] 校门：刷校园卡或人脸识别进入
- [x] 宿舍门禁：每晚 23:00 左右锁门（详见 03-dorm.md）
- [x] 外来人员：须在大门登记，说明事由并出示身份证
- [x] 机动车入校：须办理校内通行证

## 13.4 消防安全

保卫处负责全校消防安全管理，制定消防安全管理办法，负责消防器材的购置、配备、检查与维护。定期组织消防演练和消防知识培训。对易燃、剧毒、放射源等危险物品进行安全监督。宿舍严禁使用大功率违章电器（详见 03-dorm.md）。

- [x] 消防管理：保卫处统一负责
- [x] 消防演练：每学期定期组织
- [x] 宿舍禁用：大功率电器（>800W）、明火、易燃物品
- [x] 实验室安全：各实验室有专门的安全管理规定

## 13.5 治安与报案

保卫处负责校园治安巡逻、维护校园秩序、预防各类刑事案件和治安案件。配合公安机关调查处理校内各类刑事和治安案件，协调处理纠纷。校园监控系统覆盖各主要区域，提供技术防范保障。在校内遇到盗窃、诈骗、冲突等安全事件，第一时间拨打校园报警电话 **025-83787110**。

- [x] 校园报警：**025-83787110**（24 小时）
- [x] 辖区派出所：西康路—宁海路派出所 / 江宁—江宁开发区派出所 / 常州—金坛分局
- [x] 报案流程：拨打校园报警电话 → 保卫处到场 → 视情移交派出所处理
- [x] 监控覆盖：校园主要区域均安装监控摄像头
- [x] 反诈提醒：保卫处定期发布防诈骗通知，谨防刷单、冒充客服、虚假贷款等电诈

## 13.6 交通管理

保卫处负责校内交通秩序管理，包括机动车限速、停车管理、非机动车停放等。校内机动车辆须遵守限速规定并停放在指定车位。电动自行车和自行车须停放在划线区域。交通科电话：**025-83786733**。

- [x] 校内限速：一般为 20 km/h
- [x] 停车：须在指定车位停放
- [x] 电动车：部分校区限制电动车入校（详见 08-transport.md）
- [x] 交通科：**025-83786733**
