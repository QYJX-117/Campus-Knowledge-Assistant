## 6.4 就诊流程

- [x] 是否需要预约：否 ☑（直接现场挂号就诊）
- [x] 挂号方式：现场 ☑（无线上预约系统）
- [x] 挂号费：约 **2—5 元/次**（普通门诊），以校园卡刷卡扣费
- [x] 就诊需携带：校园卡 ☑ / 身份证 ☑（备用）/ 病历本 ☑
- [x] 是否有就诊病历本：是 ☑
  - 病历本名称：**《河海大学医院门诊病历》**
  - 病历本领取/购买方式：首次就诊时在校医院挂号处免费领取或象征性收费领取
- [x] 能否使用医保实时结算：能 ☑（校医院就诊时通过校园卡结算，直接减免，自付约 20%）
- [x] 就诊流程（完整版）：

```
携带校园卡 + 病历本 → 挂号收费处挂号（取号）
→ 相应科室就诊（医生诊断、开药或开转诊单）
→ 如需取药：凭处方到药房取药
→ 如需化验/检查：到检验科/放射科做检查，取报告后回诊室
→ 挂号收费处缴费结算（校园卡扣费，医保实时减免）
```

- [x] 补充说明：若校园卡无法正常使用，可携带学生证、身份证或社保卡到校医院 302 室激活

## 6.5 大学生医保

### 参保基本信息

- [x] 参保对象：本科生 ☑ / 研究生 ☑ / 博士生 ☑（全日制在校生均须参加）
- [x] 参保方式：统一参保 ☑（学校统一组织，遵循"学籍地参保"原则）
- [x] 医保年度：每年 **9 月** 至次年 **8 月**（按学年）
- [x] 医保缴费标准：
  - 南京校区（西康路+江宁）：**约 180—230 元/人/年**（2022年后入学标准为 180 元/年，后续年度以南京市医保局公布为准），按学制一次性缴纳（本科四年约 720 元）
  - 常州校区（金坛）：**260 元/人/年**（2025年度标准，含长护险），困难大学生由政府财政全额资助
- [x] 缴费方式：随学费代扣 ☑（通过学校统一划扣建行龙卡代收）
- [x] 医保卡/社保卡申领方式：入学后由学校统一采集电子证件照（358×441 像素，蓝或红底），集中办理《南京市民卡》/《江苏省社会保障卡》，约 1—2 个月发卡。常州校区由学校统一办理常州社保卡
- [x] 医保生效时间：自大一入学当天即生效，不存在等待期

## 6.6 转诊与报销

### 转诊规定

- [x] 校外就医是否需要校医院转诊：是 ☑（普通门诊必须经校医院转诊方可报销；急诊除外）
  - 转诊流程：**到校医院/江宁卫生所就诊 → 医生评估病情，认为需校外进一步诊治 → 医生开具《转诊单》 → 持转诊单到校外定点医院就诊**
  - 转诊单可在看病前或看病后去校医院开具，**一次报销只需一张转诊单**（同一病程）
  - 转诊有效期：一般 **7—14 天**（以转诊单上标注为准）
- [x] 急诊是否需要转诊：否 ☑（急诊可直接到就近医保定点医院就诊，无需预先办理转诊，报销时说明急诊情况）
- [x] 南京本地住院转诊要求：
  - 二级及以下定点医院：直接凭社保卡办理住院
  - 二级以上综合医院：需先到校医院（或江宁卫生所、任意定点社区医院）办理转诊手续
  - 专科医院（脑科医院、妇幼保健院等）：**无需转诊**，直接凭社保卡就诊

### 医疗费用报销流程

- [x] 完整报销流程：
```
① 校医院就诊 → 校园卡直接结算（实时减免）
② 转诊至校外定点医院 → 先自费垫付，保留所有单据
③ 整理报销材料 → 在规定时间到校医院三楼 302 室递交
④ 校医保办审核 → 送市医保中心审核（约 1—2 周）
⑤ 接到通知 → 周二或周四到 302 室领取报销款（现金）
```

- [x] 报销所需材料：
  - ☑ 发票原件（医疗门诊/住院收费票据）
  - ☑ 费用明细清单
  - ☑ 转诊单（急诊除外，但需在病历中体现急诊性质）
  - ☑ 校园卡/身份证
  - ☑ 病历（含就诊记录）
  - ☑ 其他：住院需另附出院小结、住院病历复印件；异地住院需另附学院盖章的说明材料

- [x] 报销受理时间：
  - 校外普通门诊报销：每年 **6 月份的每周二、周四**（集中报销期）
  - 人身意外门诊费用报销：**每周二、周四**（全年均可）
  - 材料递交：周一至周五均可，报销款领取限周二、周四
  - 具体时间段：上午 8:30—11:30，下午 14:00—17:00（以当次通知为准）

- [x] 报销受理地点：
  - 西康路：校医院三楼 **302 室**
  - 江宁：校医院/江宁卫生所（具体房间以现场指引为准）
  - 常州：常州校区卫生所（具体房间以现场指引为准）

- [x] 报销款到账时间：材料齐全后约 **1—2 周**（5—10 个工作日）可领取

- [x] 异地就医（寒暑假/实习期间）报销政策：
  - 因急危重症需在异地住院的，可就近到当地医保定点医疗机构或公立医院就诊，费用先由个人全额垫付
  - 出院后流程：到校医院说明情况 → 领取表格 → 所在学院盖章 → 将住院材料交校医院 → 校医保办送市医保中心审核 → 等待通知 → 报销款汇入学校账户后分发学生
  - 异地普通门诊一般不报销（特殊情况需提前报备）

- [x] 毕业生医保退保/转出流程：
  - 毕业离校后大学生医保自动终止（至当年 8 月 31 日）
  - 参加工作后由单位办理职工医保参保，社保卡可继续使用
  - 未就业毕业生可到户籍所在地办理城乡居民医保续保
  - 无需个人主动办理退保，学校统一处理

## 6.8 体检服务

### 新生入学体检

- [x] 体检时间：每年 **9 月上旬**（新生报到后 1—2 周内），2025 年为 9 月 6 日至 11 日
- [x] 体检地点：
  - 西康路校区：本部校医院
  - 江宁校区：江宁校区文体中心
  - 常州校区：常州校区卫生所
- [x] 体检项目（共 7—8 项）：
  1. 身高体重（电子秤测量）
  2. 血压
  3. 内科（询问病史、听诊器检查）
  4. 外科（身体检查，做下蹲、摸脚尖等动作）
  5. 胸部前后位（胸片 DR）（不能佩戴首饰，女生需盘发）
  6. ALT 肾功三项（抽血）
  7. 血常规（与 ALT 同时抽血，共扎一次）
  8. 视力检查（部分年份包含）
- [x] 体检费用：
