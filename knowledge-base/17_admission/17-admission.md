## 17.1 管理机构与信息渠道

河海大学招生工作分本科和研究生两条线。本科招生办公室负责全国普通高考招生和特殊类型招生，官网 **zsw.hhu.edu.cn** 提供招生简章、专业目录、历年分数、录取查询。研究生招生办公室（研招办）设在研究生院内，官网 **gs.hhu.edu.cn** 发布硕士、博士招生简章、推免通知、复试安排。国际学生招生由国际教育学院负责，在线申请系统为 **admission.hhu.edu.cn**。

## 17.4 研究生招生

研究生招生信息通过 **gs.hhu.edu.cn** 统一发布。硕士推免一般在每年 9—10 月，全国统考初试在 12 月下旬，复试在次年 3—4 月。博士招生以申请考核制为主。

- [x] 硕士推免时间：每年 **9—10 月**
- [x] 硕士统考时间：初试 **12 月下旬**，复试次年 **3—4 月**
- [x] 博士招生：申请考核制为主
- [x] 研究生招生简章含：招生专业目录、参考范围、院系联系方式

## 17.5 国际学生招生

河海大学是国家首批授权可授予外国留学生博士、硕士、学士学位的高校。2025/2026 学年有 62 个中文授课本科专业。申请条件：非中国籍、身心健康、18-30 周岁、高中毕业、HSK4 级及以上。详见 16-intl.md §16.4。

- [x] 国际招生官网：**admission.hhu.edu.cn**
- [x] 本科学费：20,000 元/年
- [x] 奖学金：中国政府奖学金 / 河海大学一/二/三等奖学金

## 17.6 校园开放日与咨询

学校每年高招季（6—8 月）举办校园开放日和线上线下招生咨询活动。考生和家长可在高招季拨打招办电话或通过各省招生组咨询。

- [x] 校园开放日：每年高招季（6—8 月）
- [x] 线上咨询：招生网站 / 微信公众号 / 各省招生组 QQ 群
