## 11.2 奖学金

### 国家级奖学金

- [x] **国家奖学金**：
  - 评选对象：本科生 ☑ / 研究生（硕士）☑ / 研究生（博士）☑
  - 金额：本科生 **10,000 元/人**（2024年起由8,000元提高），硕士生 **20,000 元/人**，博士生 **30,000 元/人**
  - 评选时间：每年 **9—10 月**
  - 评选条件（本科生）：学业成绩排名专业前 **10%**（或前30%且其他方面特别突出），无不及格科目，综测排名前列；研究生：学术成果突出、品学兼优
  - 名额分配方式：由教育部/全国学生资助管理中心下达名额至学校，学校按学院/学科分配
  - 申请流程：个人申请 → 班级/年级评议 → 学院初审公示 → 学校审核公示 → 报教育部审批 → 发放（通常在12月前到账）
  - 是否可与其他奖学金兼得：与学业奖学金可兼得，与 **国家励志奖学金不可兼得**；同一学历阶段同一奖项不可重复获得
  - 来源：河海校政〔2020〕146号《河海大学本科生国家奖学金评选办法》

- [x] **国家励志奖学金**：
  - 评选对象：本科生（家庭经济困难 + 成绩优秀），须通过困难生认定
  - 金额：**6,000 元/人**（2024年起由5,000元提高）
  - 评选条件：学业成绩排名专业前 **50%**，无不及格科目，已通过家庭经济困难学生认定
  - 与国家奖学金是否冲突：是 ☑（同一学年不可兼得）
  - 来源：财教〔2024〕181号及河海大学相关评选办法

### 校级奖学金

- [x] **学业优秀奖学金/优秀学生奖学金**：
  - 等级设置：不分等级
  - 金额：**1,000 元/人**
  - 评选比例：不超过专业人数 **20%**
  - 评选依据：绩点排名 ☑ / 综合测评 ☑
  - 评选时间：每学年 **9—10 月**
  - 是否自动评选还是需要申请：由学院依据学年成绩和综测排名评定，需学生确认或提交申请
  - 来源：《河海大学本科生奖学金及荣誉称号评选办法》

- [x] **单项奖学金**：
  - **学业进步奖**：金额 **500 元/人** / 条件：学年内学习成绩进步显著，不超过专业人数 **10%**
  - **科技创新奖**：金额 **500 元/人** / 条件：在校级以上学科竞赛获奖或发表论文/专利等，不超过专业人数 **5%**
  - **社会工作优秀奖**：金额 **400 元/人** / 条件：在学生组织/社团中担任骨干且表现突出，不超过专业人数 **5%**
  - **艺术体育优秀奖**：金额 **400 元/人** / 条件：在文艺/体育竞赛中获校级以上奖励，不超过专业人数 **5%**
  - **精神文明奖**：金额 **500 元/人** / 条件：在思想道德、志愿服务、见义勇为等方面表现突出，不超过专业人数 **10%**

  - **徐芝纶力学专业优秀学生奖学金**：金额 一等奖 **2,000 元/人**、二等奖 **1,000 元/人**

  - 等级与金额（后续学年）：特等 **12,000 元/年** / 一等 **10,000 元/年** / 二等 **8,000 元/年** / 三等 **4,000 元/年**
  - 第一学年：一等 **10,000 元**（~25%）/ 二等 **7,000 元**（~25%）/ 三等 **0 元**（~50%）
  - 覆盖比例：**100%**（全覆盖，动态管理，各等级比例以当年文件为准）
  - 评选时间：第一学年按入学成绩/推免等评定，后续学年依据综合表现每年 **9—10 月**评定
  - 来源：《河海大学研究生奖助学金管理办法（2022版）》

## 11.3 助学金（困难补助）

- [x] **国家助学金**：
  - 对象：家庭经济困难本科生（须通过困难生认定）
  - 等级与金额：一等 **4,000 元/年** / 二等 **3,000 元/年** / 三等 **2,000 元/年**（平均标准 3,700 元/年，2024年秋起）
  - 申请时间：每学年 **9—10 月**（通过"江苏省学生资助申请平台"申请）
  - 发放方式：按学期发放 ☑（秋季、春季各发一半）
  - 特别说明：建档立卡家庭、农村低保、孤残、烈属子女原则上评定一等；全日制在校退役士兵学生全部享受，标准 **3,300 元/年**
  - 来源：学工处资助政策、财教〔2024〕181号

- [x] **家庭经济困难学生认定（困难生认定）**：
  - 认定时间：每学年 **9 月**（新生入学后集中认定）
  - 认定等级：特别困难 ☑ / 困难 ☑ / 一般困难 ☑（三个等级）
  - 所需材料：家庭经济困难学生认定申请表（无需盖章但需个人承诺并签字）、相关证明材料（低保证/残疾证/病历等，如有）
  - 认定流程：学生提交申请 → 辅导员家访（线上或线下，须前置完成）→ 年级民主评议 → 学院审核公示 → 学校备案入库
  - 是否需要每年重新认定：是 ☑
  - 来源：《河海大学家庭经济困难本科生认定办法》（河海校政〔2019〕17号）、《河海大学家庭经济困难研究生认定办法》（河海校政〔2019〕96号）

- [x] **研究生国家助学金**：全覆盖
  - 硕士：**7,000 元/年**（按10个月发放，每月700元，7月、8月不发）
  - 博士：第一学年 **18,000 元/年**，其他学年 **20,000 元/年**
  - 来源：《河海大学研究生奖助学金管理办法（2022版）》

- [x] **研究生"三助"（助教/助研/助管）津贴**：
  - 申请方式：通过学院/导师/用工单位发布岗位信息，学生自主申报
  - 薪酬标准：约 **400—800 元/月**（根据岗位类型和工作量确定）
  - 来源：《河海大学研究生奖助学金管理办法（2022版）》

- [x] **社会助学金**（部分列出）：
  - **瑞华启梦助学金**：**5,000 元/人**
  - **瑞华春雨助学金**：**2,000 元/人**（面向新生，约300人）
  - **吴毅文助学金**：**5,000 元/人**
  - **大禹奖助学金**：**3,000 元/人**
  - **钱正英助学金**：**3,000 元/人**
  - **真维斯助学金**：按年级分档，最高 **5,000 元/人**
  - 来源：学工处资助政策、机电工程学院资助政策简介

- [x] **临时困难补助**：
  - 申请条件：学生本人或家庭遭遇突发性、临时性困难（如重大疾病、自然灾害、家庭变故等）
  - 申请流程：学生本人向辅导员提出申请 → 填写《临时困难补助申请表》→ 学院审核 → 学工处审批 → 发放
  - 补助金额范围：**500 元 — 5,000 元**（视困难程度确定，特殊情况可一事一议）
  - 来源：学工处资助科

- [x] **专项补助**：
  - **寒衣补助/冬衣补助**：有 ☑ 每年冬季为家庭经济特别困难新生发放
  - **返乡路费补助**：有 ☑（车票补贴 **200 元/人**，约50人）
  - **节日慰问补助**：有 ☑（春节等重大节日慰问困难学生）

  - **求职补贴（毕业生）**：有 ☑ 金额以当年人社部门通知为准（通常 **1,500 元/人**）
  - **卧具补贴**：有 ☑ **400 元/人**（约50人）
  - **教材资助**：有 ☑ 面向家庭经济特别困难学生
  - 来源：学工处资助政策、迎新工作通知

## 11.4 助学贷款

- [x] **生源地信用助学贷款**：
  - 办理时间：每年 **6 月 — 9 月**（暑假期间）
  - 办理地点：户籍所在地县/区教育局学生资助管理中心
  - 贷款机构：国家开发银行（为主）或当地农村信用社
  - 贷款额度：本科最高 **16,000 元/年**，研究生最高 **20,000 元/年**
  - 在校期间是否贴息：是 ☑（政府全额贴息）
  - 毕业还款开始时间：毕业后有 **3 年宽限期**（宽限期内仅还利息），宽限期后还本付息；贷款期限为学制+15年，最长不超过22年
  - 在校生续贷流程：每年 **5 月**在国家开发银行系统中填写续贷声明 → 提交续贷申请 → 开学后将《贷款受理证明》回执交至学院 → 学院统一交学工处
  - 学校需要出具什么材料：在校证明、贷款回执单（由学工处统一处理）
  - 贷款发放：银行于每年 **11—12 月**放款至学校账户，学校财务处代扣学费住宿费，余额退还至学生建设银行卡

- [x] **校园地国家助学贷款**：
  - 是否开办：是 ☑
  - 合作银行：**中国银行**
  - 办理时间：入学后 **9—10 月**（开学后1-2个月内）
  - 所需材料：中国银行卡（激活）、学生证/录取通知书、身份证、家庭经济困难认定表、贷款申请表等
  - 办理流程：登录学生信息管理系统填写贷款合同 → 提交材料至学工处资助科 → 审核通过后与中国银行签订贷款合同 → 一次签约四年，分学年发放
  - 贷款发放：每年 **12 月至次年 3 月**放款
  - 注意：同一学年内**不能同时申请**生源地贷款和校园地贷款，只能二选一

- [x] **贷款毕业生毕业确认流程**：
  - 毕业学年 **5 月**登录贷款系统（国家开发银行/中国银行）完成毕业确认
  - 更新联系方式、就业信息等
  - 校园地贷款毕业生须与中国银行当场签订还款协议

- [x] **贷款咨询渠道**：
  - 学工处资助科：**025-58099478**
  - 国家开发银行助学贷款服务热线：**95593**
  - 中国银行客服热线：**95566**
  - 全国学生资助管理中心网站：**https://www.xszz.edu.cn**

- [x] **贷款代偿/补偿政策**：
  - **基层就业**：到中西部地区、艰苦边远地区和老工业基地县以下基层单位就业，服务期 **3 年以上**，可申请学费补偿或贷款代偿，本专科生最高 **16,000 元/年**，研究生最高 **20,000 元/年**，分3年拨付
  - **应征入伍**：入伍时对在校期间学费一次性补偿或贷款代偿，本专科生最高 **20,000 元/年**（2024年9月起新标准）、研究生最高 **25,000 元/年**（2024年9月起新标准）；退役复学后享受学费减免
  - 来源：学工处2024年《关于做好2024届毕业生基层就业学费补偿和国家助学贷款代偿相关工作的通知》

## 11.5 勤工助学

- [x] 勤工助学岗位类型：
  - 校内行政管理助理 ☑（行政助理岗位：**450 元/月**）

## 11.8 学费减免与补偿

- [x] **学费减免政策**：
  - 适用对象：孤儿 ☑ / 残疾学生 ☑ / 烈士子女 ☑ / 家庭遭受自然灾害学生 ☑
  - 减免标准：减免金额范围 **1,000 — 6,380 元**（视实际情况确定，特殊情况可全免）
  - 申请流程：学生提交申请 → 学院审核 → 学工处审批 → 财务处执行
  - 申请时间：每年秋季学期（新生入学后）
  - 来源：学工处资助政策

- [x] **应征入伍学费补偿/贷款代偿**：
  - 补偿标准：本专科生最高 **20,000 元/年**（2024年9月起新标准），研究生最高 **25,000 元/年**（2024年9月起新标准）
  - 申请流程：登录全国征兵网填写《应征入伍服兵役高等学校学生国家教育资助申请表I》→ 学校学生资助部门审核盖章 → 入伍地县级征兵办盖章确认 → 批准入伍后将申请表原件、入伍通知书复印件、身份证复印件、银行卡复印件交至学校 → 学校复核后落实补偿/代偿（通常入伍后半年至一年内发放）
  - 退役复学：退役后自愿复学或入学的，享受学费减免

- [x] **基层就业学费补偿/贷款代偿**：
  - 适用条件：应届毕业生自愿到中西部地区、艰苦边远地区和老工业基地的县以下（不含县级）基层单位就业，服务期 **3 年以上**
  - 补偿标准：本专科生最高 **16,000 元/年**，研究生最高 **20,000 元/年**
  - 补偿方式：资金分 **3 年**拨付完毕，每年发放总金额的 **1/3**；第二、第三年需继续提交《在职在岗证明表》
  - 申请流程：学校发布通知（通常在每年6月）→ 毕业生提交申请材料 → 学校审核 → 报全国学生资助管理中心审批 → 分年发放
  - 来源：学工处2024年《关于做好2024届毕业生基层就业学费补偿和国家助学贷款代偿相关工作的通知》

- [x] **退役士兵学费资助**：
  - 退役后考入河海大学的全日制在校生，可享受学费资助，标准参照服兵役学费补偿标准
  - 全日制在校退役士兵学生全部享受国家助学金，标准为 **3,300 元/年**
  - 来源：国家教育资助政策
