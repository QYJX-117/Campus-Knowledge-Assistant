# 18 — 校园服务

> 数据来源：河海大学后勤管理处 (hqglc.hhu.edu.cn)、资产经营公司
> 更新周期：每学期核实一次（商铺和服务变动较频繁）
> 最近更新：2026-07-18

## 18.1 校园超市

三校区均配备教育超市或便利店，满足日常购物需求。江宁校区有 4 个超市：教育超市（致高楼 A 栋一楼和六食堂一楼各一家）、爱心超市（六食堂附近二楼，文创+西装租借）、生活超市（26 舍楼下，品类最丰富，含零食/日用品/水果/文具/教辅）。常州校区有 3 个便利店：15 号楼/48 号楼（7:00—22:00）、罗森超市（42 号楼，7:00—23:00）。西康路校区校内有教育超市。支持校园卡、支付宝、微信付款。

- [x] 江宁超市：教育超市（致高楼A/六食堂各一）+ 爱心超市（文创+西装租借）+ 生活超市（26舍楼下）
- [x] 常州便利店：15 号楼、48 号楼（7:00—22:00）+ 罗森（42 号楼，7:00—23:00）
- [x] 西康路：教育超市
- [x] 付款方式：校园卡 ☑ / 支付宝 ☑ / 微信 ☑
- [x] 校外补充：江宁南门对面华诚超市；地铁一站到翠屏山站华润苏果

## 18.2 文印打印

江宁校区每栋宿舍楼下均配自助打印机（24 小时可用，手机扫码），8 舍楼下有苏携图文打印店（可购复习资料）。常州校区每个宿舍管理站设自助打印机（24 小时），42 号楼和 54 号楼各有文印店（8:00—22:00）。西康路校区校内及南边一条街均有打印店，约 **0.1—0.12 元/页**。

- [x] 自助打印机：江宁每栋宿舍楼下 / 常州每个管理站，24 小时，手机扫码
- [x] 文印店：江宁 8 舍楼下 / 常州 42 号+54 号楼 / 西康路南边街
- [x] 价格：约 0.1—0.12 元/页（A4 黑白）
- [x] 图书馆自助打印：A4 黑白 0.12 元/张（详见 01-lib.md §1.9）

## 18.3 理发

江宁校区南边一条街有理发店。常州校区理发店位于 19 号楼 128 室，运营时间 8:00—22:00。西康路校区周边社区有多家理发店。

- [x] 江宁：校区南边一条街
- [x] 常州：19 号楼 128 室，8:00—22:00
- [x] 西康路：周边社区

## 18.4 维修服务

维修服务中心负责教学区和生活区的日常水电设备运行维护、零星修缮和故障修复。常州校区可拨打报修电话 **0519-85130016** 或向宿管登记。

- [x] 报修方式：宿管登记 / 拨打 0519-85130016（常州）
- [x] 宿舍维修：详见 03-dorm.md §3.6

## 18.5 失物招领

后勤服务网站设有"失物招领中心"，楼宇管理部在教学楼值班管理中提供失物招领服务。此外后勤网站"在线沟通"栏目可反馈问题和建议。

- [x] 线上：后勤服务网站 → 失物招领中心
- [x] 线下：各教学楼值班室 / 图书馆服务台 / 保卫处
- [x] 反馈渠道：后勤网站"在线沟通"栏目

## 18.6 外卖

江宁校区和常州校区校门口设有外卖货架/取餐柜。外卖不进校，须到指定校门自取。

- [x] 江宁：校门口外卖柜
- [x] 常州：东门、西门设外卖货架
- [x] 西康路：因校区小且处市中心，外卖取餐方便

## 18.7 校园网络与一卡通

校园网 WiFi（SSID: Hohai University）、校园卡充值挂失等详见 **05-it.md** 和 **04-card.md**。
