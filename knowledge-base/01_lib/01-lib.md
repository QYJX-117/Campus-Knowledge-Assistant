## 1.1 基本信息

- [x] 图书馆全称：**河海大学图书馆**
- [x] 历史沿革：源于 1915 年河海工程专门学校图书室，1958 年建成首座独立馆舍，1985年更名为河海大学图书馆
- [x] 校区分布：**西康路校区** ☑ / **江宁校区** ☑ / **常州（金坛）校区** ☑
- [x] 馆舍总面积：**9.26 万平方米**（西康路 0.87 万㎡ / 江宁 4.1 万㎡ / 常州 4.09 万㎡ / 院系资料室 0.2 万㎡）
- [x] 阅览座位：**7681 席**，年均接待读者逾 250 万人次
- [x] 馆藏纸质文献：**353.35 万余册**（截至 2024 年底）
- [x] 电子资源：**78 个中外文数据库**（含 259.4 万余册电子图书、7.7 万余种电子期刊）
- [x] 馆藏特色：以水利为特色，理、工、文、管、经、法全面覆盖
- [x] 各校区图书馆地址：
  - 西康路：江苏省南京市鼓楼区西康路 1 号
  - 江宁：江苏省南京市江宁区佛城西路 8 号
  - 常州：江苏省常州市金坛区河海大道 1915 号
- [x] 官网地址：**https://lib.hhu.edu.cn**
- [x] OPAC（馆藏查询）：**http://opac.hhu.edu.cn/**
- [x] 微信公众号名称：**河海大学图书馆**
- [x] 智能客服：官网右下角嵌入超星机器人客服
- [x] 移动端：手机移动图书馆、学习通 APP
- [x] 咨询邮箱：tsgbgs@hhu.edu.cn

## 1.3 入馆方式

- [x] 是否需要预约入馆？**否**（但有座位使用需求则需预约座位）
- [x] 入馆凭证：
  - **校内读者**：凭本人校园卡刷卡入馆（校园卡即借阅证），仅限本人使用，严禁代借冒借（违者停借 30 天）
  - 未携带校园卡或无法使用时：出示学生证/工作证等有效证件，或提供奥蓝系统/教务系统本人信息，经查验后登记入馆
  - **校友读者**：出示电子校友卡，登记入馆
  - **社会读者**：凭临时借阅证及身份证，登记入馆
  - **其他来访者**：出示身份证等有效证件，同意并登记后入馆
- [x] 新生：本科生须通过"新生入馆教育"在线测试后方可开通借书权限
- [x] 衣冠整洁得体，严禁携带易燃易爆物品，禁止在馆内饮食、吸烟，禁止使用大功率电器

## 1.4 借阅规则

### 借阅权限（最新版）

| 读者类型 | 中文图书 | 中文借期 | 外文图书 | 外文借期 | 最大总册数 |
|----------|:------:|:------:|:------:|:------:|:--------:|
| **本科生** | 20 册 | 45 天 | 1 册 | 30 天 | 21 册 |
| **研究生（全日制）** | 30 册 | 90 天 | 5 册 | 60 天 | 35 册 |
| **研究生（基地生）** | 5 册 | 365 天 | 1 册 | 365 天 | 6 册 |
| **教工（含博后、进修教师、访问学者）** | 30 册 | 90 天 | 5 册 | 60 天 | 35 册 |
| **智盟卡读者** | 5 册 | 30 天 | — | — | 5 册 |

### 续借规则

- [x] 续借时间：须在图书**到期前 7 天内**办理（中文图书）/ 到期前 10 天内（FAQ 提及）
- [x] 续借次数：每种图书**只可续借 1 次**
- [x] 续借期限：中文图书续借 **15 天**（FAQ版本：本科生10天、研究生/教工30天，以最新规章为准）
- [x] 续借方式：
  1. 持书到馆通过自助借还机续借
  2. 登录图书馆主页"我的图书馆"网上续借
  3. 移动图书馆 / 微信公众号续借

### 借还书注意事项

- [x] 办理借书时须持本人校园卡，仔细核对借阅信息
- [x] 还书无需校园卡，可委托他人代还
- [x] 当天所还图书本人不得再借（提高周转率）
- [x] 本校区图书可通过自助借还机归还
- [x] **通借通还**：三校区图书可异地归还（在任一校区服务总台或自助机）

### 预约与委托借阅

- [x] **预约借书**：所需图书本校区一线借阅区全部借出时，可通过图书馆主页/微信公众号/学习通在线预约，到书后保留 **7 天**（FAQ版本：5天）
- [x] **委托借阅**：本校区二线书库或异校区有馆藏时，可办理委托借阅
  - 本校区二线书库委托：到书周期 **24 小时**
  - 异校区委托：到书周期 **3 个工作日**（周六日及节假日除外）
  - 到书后保留期限：**7 天**

### 逾期罚款

- [x] 超期 10 天内（含 10 天）：**0.05 元/册/天**
- [x] 超期 10 天以上：**0.10 元/册/天**
- [x] 节假日/寒暑假到期的图书，借期自动顺延至节假日后次日或假期结束后 7 日内

### 遗失赔偿

- [x] 可购买同版本图书赔偿，或按图书价格的 **3—5 倍**赔偿
- [x] 损坏（含涂画）：每册罚款 **2 元起**
- [x] 偷盗图书：通报批评 + 原书价 **10 倍**罚款

### 通用借书证

- [x] **江苏省高校通用借书证**（教工及硕博士）：每年 4 月和 10 月左右登记办理，详见图书馆主页公告
- [x] **南京高校（江宁地区）联合体通用借书证**（本科生）：凭校园卡+学生证+一寸照片，到江宁校区图书馆三楼电子阅览室免费办理
- [x] 跨校区通借通还：三校区支持，详见上述预约与委托规则
