## 0.1 学校简介

河海大学（Hohai University，简称"河海"、"HHU"），位于江苏省南京市，是一所以**水利为特色，工科为主，多学科协调发展**的教育部直属全国重点大学。学校是**国家"211工程"重点建设高校**（1996 年）、**"985工程优势学科创新平台"建设高校**（2008 年）、**国家"双一流"建设高校**（2017 年首批、2022 年第二轮），也是经国家批准设立研究生院的 56 所高校之一，全国首批具有博士、硕士、学士三级学位授予权的高校。学校被誉为"水利高层次创新创业人才培养的摇篮和水利科技创新的重要基地"，素有水利行业**"黄埔军校"**之美誉。

## 0.2 历史沿革

河海大学的历史可追溯至 1915 年，是中国第一所培养水利人才的高等学府，开创了中国水利高等教育的先河。百年历程中几经更名与合并，但始终以水利为特色。

| 年份 | 事件 |
|:----:|------|
| **1915** | 张謇创办**河海工程专门学校**，黄炎培任筹备主任，许肇南任首任校长，李仪祉任教务主任 |
| 1924 | 与东南大学工科合并成立**河海工科大学**，茅以升任首届校长 |
| 1927 | 并入第四中山大学（后历经中央大学、南京大学等） |
| **1952** | 全国院系调整，南京大学、交通大学、同济大学、浙江大学等水利系科合并成立**华东水利学院**，钱正英为首任院长 |
| 1960 | 被中共中央认定为**全国重点大学** |
| **1985** | 恢复传统校名**"河海大学"**，**邓小平**亲笔题写校名 |
| 1996 | 入选国家**"211工程"**重点建设高校 |
| 2008 | 入选**"985工程优势学科创新平台"**建设高校 |
| 2017 | 入选国家首批**"双一流"**建设高校 |
| 2022 | 再次入选第二轮**"双一流"**建设高校 |

> 来源：https://www.hhu.edu.cn/16347/list.htm 、 百度百科
