## 2.4 支付方式

- [x] 校园卡：支持 ☑（各食堂通用，窗口刷卡）
- [x] 微信/支付宝：支持 ☑（聚合支付，直接使用付款码消费）
- [x] 云闪付/中行APP/建行APP：支持 ☑（聚合支付渠道之一）
- [x] 现金：不支持（食堂窗口一般不收现金，需使用电子支付或校园卡）

### 校园卡充值方式

- [x] **线上充值（推荐）**：
  1. 微信公众号 **「河海大学网信办」** → 网信服务 → 自助校园卡 → 卡片充值
  2. **中国银行 APP** → 校园卡充值入口
- [x] **线下充值**：
  - 自助圈存机（位置：六食堂教育超市旁等）
  - 各校区服务大厅/卡务中心
- [x] 初始查询密码：身份证后六位（含字母则取倒数第七位至倒数第二位）
- [x] 注：使用聚合支付前需先完成虚拟卡认证绑定，否则无法查询个人消费流水
