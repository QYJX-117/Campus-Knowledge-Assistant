## 15.1 机构基本信息

河海大学心理健康教育与研究中心（简称"心理中心"）是面向全校学生提供心理健康服务的专门机构，隶属于学生工作处。心理中心为在校学生提供免费心理咨询、心理评估、危机干预、心理健康教育等服务。官方网站为 xsc.hhu.edu.cn 下的心理健康板块，微信公众号为"**河海大学心理中心**"。服务覆盖西康路、江宁、常州三校区。

心理中心遵循心理咨询的专业伦理，对来访者的个人信息和咨询内容严格保密，但以下三种法定例外情形除外：(1) 来访者有伤害自己或他人的危险；(2) 未成年人受到虐待或忽视；(3) 法律要求披露。

- [x] 心理中心全称：**河海大学心理健康教育与研究中心**
- [x] 隶属：学生工作处
- [x] 微信公众号：**河海大学心理中心**
- [x] 官网：**https://xsc.hhu.edu.cn**（学生处 → 心理健康板块）
- [x] 覆盖校区：西康路 ☑ / 江宁 ☑ / 常州 ☑
- [x] 保密原则：咨询内容严格保密，三种法定例外情形除外

## 15.2 心理咨询预约

心理咨询须**提前预约**。每学期自第二周开始服务，一般为每周一次、每次 50 分钟，可提供面对面咨询和网络咨询。在校学生享有 **8 次免费**咨询机会，8 次之后如需继续须提交书面申请。如因故不能前来，须至少提前 2 小时取消预约。

- [x] 预约方式（三种）：

| 方式 | 详情 |
|------|------|
| **奥兰系统** | 登录 → "心理咨询"板块 → 在线预约 |
| **电话预约** | **025-58099002**（周一至周五 14:00—17:00 / 18:30—20:30） |
| **QQ 预约** | 添加 **2089555787**，验证格式：学号+姓名+学院 |

- [x] 预约流程：添加 QQ → 验证身份 → 填写《知情同意书》和《来访者信息登记表》 → 确定咨询时间
- [x] 咨询频率：每周一次，每次 **50 分钟**
- [x] 费用：**免费**（前 8 次），后续须书面申请
- [x] 取消规则：**提前 2 小时**来电取消

## 15.4 寒暑假安排

寒暑假期间心理中心安排线上心理咨询值班，学生仍可通过电话或 QQ 预约。假期校内紧急情况可拨打 24 小时热线。具体值班时间每学期末通过微信公众号公告。

- [x] 假期：线上咨询值班 + 24 小时热线持续
- [x] 公告渠道：微信公众号"河海大学心理中心"

## 15.5 心理普查

心理普查由心理中心在每学年开学初统一组织，一般通过奥兰系统下发测评问卷，全体新生须参加。普查结果仅用于心理健康筛查和后续针对性服务，不影响学籍和档案。

- [x] 时间：每学年开学初
- [x] 方式：奥兰系统下发测评问卷
- [x] 范围：全体新生全覆盖
- [x] 用途：心理健康筛查，不影响学籍档案

## 15.6 心理健康教育

心理中心定期举办心理健康讲座、团体辅导、心理委员培训、525 心理健康月等活动。各学院配备心理辅导员，班级设心理委员，构建"学校—学院—班级—宿舍"四级心理健康工作网络。

- [x] 活动：心理健康讲座 / 团体辅导 / 525心理健康月 / 心理委员培训
- [x] 四级网络：心理中心 → 学院心理辅导员 → 班级心理委员 → 宿舍信息员
