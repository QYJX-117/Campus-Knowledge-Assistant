# 03 — 宿舍生活

> 数据来源：河海大学后勤管理处、学生工作处、各学院新生指南、学生社区分享
> 更新周期：每学年核实一次
> 最近更新：2026-07-18

---

## 3.1 宿舍基本概况

河海大学三校区宿舍条件各有特点。江宁校区条件最优，本科生均为四人间、上床下桌、独立卫浴加阳台。西康路校区为老校区，新舍及翻新宿舍配独卫，旧舍使用公共浴室。常州金坛校区为新建校区，四人间有独卫，部分六人间为公用卫生间。住宿费每年 750—1500 元不等。所有宿舍均配备空调，入学时请仔细检查房间设施（灯、桌椅、柜子、电扇、插座、热水器、马桶等），如有损坏立即报修可免费维修。

- [x] 宿舍概况：

| 校区 | 房型 | 卫浴 | 床铺 | 住宿费 |
|------|------|------|------|:-----:|
| 江宁 | 四人间 | 独立卫浴+阳台 | 上床下桌 | ~1500 元/年 |
| 西康路（新舍） | 四人间 | 独立卫浴 | 上床下桌 | ~1500 元/年 |
| 西康路（旧舍） | 四/六人间 | 公共浴室 | 上下铺 | 750-1400 元/年 |
| 常州金坛 | 四/六人间 | 四人间独卫，六人间公用 | 上床下桌 | ~1500 元/年 |

## 3.2 空调与用电

三校区宿舍均配空调，学校每月发放一定免费电量，超出部分需自行缴费。电费通过微信公众号"河海大学财务处"或找宿管取电卡充值。**严禁使用功率大于 800W 的违章电器**（电炉、热得快、电饭煲、电磁炉、电热毯等），一经查处将按校纪处理。江宁校区实行全天供电，不熄灯不断电不停水，但晚上 11 点后需保持安静。

- [x] 空调：三校区均配备 ☑
- [x] 电费充值：微信公众号"河海大学财务处" / 找宿管取电卡充值 / 教育超市旁充值点
- [x] 违章电器限制：功率 > **800W** 的电器禁止使用
- [x] 断电/熄灯：**江宁校区不熄灯不断电**，西康路/常州视宿舍楼管理而定

## 3.3 热水与饮水

每层宿舍楼配有饮水机，提供冷热水，刷水卡或通过"诚善智能云"APP 扫码使用（部分已改为支付宝碰一碰）。教学楼、图书馆也有饮水机（仅支持水卡）。洗浴热水方面，江宁校区独立卫浴配热水器，西康路新舍有热水器、旧舍需使用公共浴室，常州四人间配热水器。

- [x] 饮水机：每层楼配备，冷热水供应
- [x] 饮水支付：水卡刷卡 / "诚善智能云"APP / 支付宝碰一碰
- [x] 水卡办理：周二 3 舍 11:30—13:30 / 周五 17 舍 11:30—13:30（水卡非实名，遗失不补）
- [x] 洗浴热水：江宁独卫有 ☑ / 西康路新舍有 ☑ 旧舍公共浴室 / 常州四人间有 ☑

## 3.4 洗衣

每栋宿舍楼一楼设有公共洗衣房，配备洗衣机、烘干机、洗鞋机、挂烫机，扫描机器二维码通过小程序使用，可实时查看洗衣进度。宿舍内**不能私自安装洗衣机**。一楼室外设有晾晒区域和统一晾被架。

- [x] 洗衣位置：每栋一楼公共洗衣房
- [x] 使用方式：扫码 → 小程序/APP 支付
- [x] 设备：洗衣机 ☑ / 烘干机 ☑ / 洗鞋机 ☑ / 挂烫机 ☑
- [x] 私自安装洗衣机：禁止
- [x] 晾晒：一楼室外晾晒区 + 晾被架

## 3.5 门禁与安全

宿舍门禁时间一般为每晚 **23:00**（各宿舍楼可能有差异）。各学院会不定期查寝和卫生检查。宿舍楼均配门禁系统，须刷校园卡进入。贵重物品请妥善保管。

- [x] 门禁时间：每晚约 **23:00**
- [x] 查寝：学院不定期检查，卫生每周检查
- [x] 门禁方式：校园卡刷卡

## 3.6 报修

宿舍设施损坏第一时间找宿管阿姨登记，或到公寓管理站填写报修单。常规维修免费，每学期有定期设备检修。**入学时务必仔细检查所有设施，入住前发现问题免费维修，入住后人为损坏可能收费**。

- [x] 报修方式：找宿管登记 / 公寓管理站报修单 / 常州校区可拨 0519-85130016
- [x] 费用：常规免费，人为损坏可能收费
- [x] 紧急维修（漏水、断电）：立即联系宿管

## 3.7 宿舍分配与调换

新生宿舍由学校统一分配，一般按学院、专业、班级集中安排。如需调换须向辅导员和学院提交书面申请，审批后方可调整。不得私自调换宿舍。

- [x] 新生分配：学校按学院/专业/班级统一安排
- [x] 调换：须辅导员+学院书面审批
- [x] 走读/校外住宿：须学院审批，一般仅限家在本地等特殊情况
