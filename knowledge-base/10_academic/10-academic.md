## 10.3 选课

- [x] 选课系统入口：**https://jwxt.hhu.edu.cn/sso.jsp**（综合教务系统），也可通过信息门户"教务系统"进入
- [x] 选课阶段及时间（本科生）：
  - 正选：学期末，约**第20周**左右（教务处具体通知）
  - 补退选：开学**第1周**内（线上进行）
  - 跨专业选修课选课：补退选之后，面向大二、大三、大四学生
  - 重修选课：另行通知（一般在开学初几周内）
- [x] 选课方式：**系统预置+自主选课+抽签** ☑
  - 必修课：系统预置到每位学生课表中，学生核对（原则上不可删除，学籍异动学生除外）
  - 部分公共必修课（思政课程、大学英语及拓展英语课程、体育课程等）：学生自主选课
  - 专业选修课及通识选修课：学生自主选课
  - 正选结束后按选课优先级和课容量抽签，不足10人的课程原则上取消
- [x] 选课学分上限：每学期重修最多不超过 **6** 门（学籍审核要求见下方学业预警）
- [x] 选课学分下限（学籍审核标准）：
  - 一年级结束：累计取得学分 ≥ 总学分的 **1/6**
  - 二年级结束：累计取得学分 ≥ 总学分的 **1/3**
  - 三年级结束：累计取得学分 ≥ 总学分的 **1/2**
- [x] 课程类型：
  - **必修课**：公共必修课、学科平台课、专业基础课、专业主干课
  - **专业选修课**：专业提升课、专业拓展课
  - **公共选修课（通识选修课）**：普通公选课、网络公选课（限大二、大三、大四学生修读，不可跨校区，每个类型最多可选2门）
  - **体育课**：分篮球、排球等多个项目，需按体育系通知选课
  - **跨专业选修课**：有 ☑（面向大二、大三、大四，不可跨校区选课，允许跨年级选课）
- [x] 通识选修课学分要求：见各专业培养方案（每个类型最多可选2门，普通公选课+网络公选课）
- [x] 跨专业/跨学院选课是否允许：是 ☑
  - 条件和限制：不可跨校区选课；允许跨年级选课；课程考核要求与专业内选课学生一致；考核不及格可重修或下学期另选其他跨专业选修课
- [x] 选课冲突检测：**系统自动检测** ☑（同一授课时段只能选修一门课程）
- [x] 课程容量已满怎么办（扩容申请）：正选结束后教务处根据选课情况和任课教师意见对课容量进行微调
- [x] 退课限制：
  - 线上退课：补退选阶段（开学第1周内）可在教务系统自行退课
  - 线下退课：逾期需在开学五周内填写《河海大学本科生补（退）选课程申请表》，所退课程实际授课时长不得超过总课时的1/3
  - 选课后未退选而无故不参加考核者，成绩登记为"旷考"，不得参加补考
- [x] 重修选课流程：
  - 在校生自行登录综合教务系统网上报名+网上缴费，不受课容量限制
  - 无法网上报名的结业换证学生、非在籍学生到所在学院教学秘书处手工报名并网上缴费
  - 重修分**跟班重修**和**组班重修**两种
  - 重修最多不超过6门；若时间冲突需向任课教师请假
  - 按学分收费
- [x] 旁听/免听：
  - 免听：自学能力较强的学生可申请不随堂听课而参加考核（需本人申请+学院及任课教师同意，作业和实践环节仍须完成）
  - 免修：成绩优秀或学有特长者可在开课前一学期末申请免修考核
  - 思想政治理论课、单独开设的实验课、实习、课程设计、毕业设计（论文）、体育、军训等课程不得申请免修、免听

> 数据来源：《河海大学全日制普通本科生选课管理实施细则（试行）》（河海教务〔2019〕62号）、河海大学本科生选课流程及有关说明 jwc.hhu.edu.cn/2013/0909/c3061a39539/page.htm、本科生正式选课线上补退选课流程 jwc.hhu.edu.cn/2025/0602/c3072a303714/page.htm

## 10.5 考试与成绩

- [x] 期末考试时间安排公布时间：约考前 **2-3** 周（教务系统可查询个人考试安排）
- [x] 考试安排查询方式：教务系统 ☑ / 微信公众号 □
  - 教务系统 → "考试安排"模块
  - 教务处官网考试安排栏目 https://jwc.hhu.edu.cn/
- [x] 考试类型：
  - 闭卷考试 ☑
  - 开卷考试 ☑
  - 半开卷考试 ☑
  - 论文/报告 ☑
  - 面试/口试 ☑
  - 综合练习/综合设计 ☑
  - 上机考试/实验操作 ☑
- [x] 缓考申请：
  - 申请条件：因特殊情况（疾病、代表学校参加竞赛等）不能按期参加考核
  - 申请流程：本人向所在学院申请 → 附相关证明 → 学院审核 → 教务处同意后方可缓考
  - 申请截止时间：考前申请（以教务处具体通知为准）
  - 所需材料：书面申请 + 相关证明（因病需附医院证明）
  - **缓考以一次为限**。缓考可随下学期初补考或随下年级跟班考核
  - 代表学校参加竞赛等特殊情况缓考：参加补考成绩不限最高分；跟班考核成绩不限最高分
- [x] 补考安排：
  - 补考时间：一般在 **下学期初**（开学前或开学第1-2周）
  - 哪些课程可以补考：**必修课（不含实践教学环节课程）和选修课（不含网络选修课）** 不及格可免费参加下学期初补考
  - 不可补考的课程：实践教学环节课程（可随下年级免费跟班重修一次）；网络选修课（可重修或选修其他网络课程）
  - 补考成绩是否覆盖原成绩：补考成绩最高为 **70分**，成绩档案中对补考、重修获得的成绩予以标注
- [x] 重修：
  - 重修条件：必修课补考仍不及格必须重修；选修课补考仍不及格可选其他课程或申请重修
  - 重修报名时间：每学期重修选课阶段（开学初，具体以教务处通知为准）
  - 重修费用：**收费** ☑，按学分收费（具体标准以当年通知为准）
  - 重修是否有次数限制：无明确规定，但总修业年限不超过6年
  - 重修分**跟班重修**和**组班重修**两种形式
  - "旷考"和考试违纪/作弊者不得参加补考，必须重修
- [x] 成绩查询方式：教务系统在线查询 https://jwxt.hhu.edu.cn/sso.jsp
- [x] 成绩发布时间：一般在课程结束后 **1-2** 周内（任课教师录入成绩后）
- [x] 成绩构成（平时分/期中/期末比例）：
  - **平时成绩不低于课程总成绩的30%**
  - 具体比例由任课教师在课程开始时向学生公布
  - 综合平时作业、实验、到课率和其他教学环节，注重能力水平和学习过程评价
- [x] 成绩异议/复核申请：
  - 申请流程：在规定时间内向任课教师或学院教学秘书提出，由任课教师核实，如需更改成绩则走"教师申请本科生课程成绩更改流程"
  - 教师成绩更改流程入口：https://myhall.hhu.edu.cn/infoplus/form/CJGG/start（办事大厅 → "本科生课程成绩更改申请"）
  - 办结时限：3个工作日
  - 咨询电话：0519-85191819
- [x] GPA/绩点计算方式：
  - 满分：**5.0** ☑

  | 百分制成绩 | 课程绩点 |
  |----------|---------|
  | 90～100 | **5.0** |
  | 85～89 | **4.5** |
  | 80～84 | **4.0** |
  | 75～79 | **3.5** |
  | 70～74 | **3.0** |
  | 65～69 | **2.5** |
  | 60～64 | **2.0** |
  | 0～59 | **0** |

  | 五级记分制 | 课程绩点 | 折换百分制 |
  |----------|---------|-----------|
  | 优秀 | 5.0 | 95 |
  | 良好 | 4.5 | 85 |
  | 中等 | 3.5 | 75 |
  | 及格 | 2.5 | 65 |
  | 不及格 | 0 | 55 |

  - **平均学分绩点** = Σ（课程学分 × 课程绩点）/ Σ 课程学分
  - 评优、评奖、免试推荐研究生以**首次考试成绩**为依据，重修后取得的课程绩点不参与平均学分绩点计算
  - "旷考"、违纪作弊：以零分计算绩点

- [x] 学分计算规则：
  - 理论教学为主的课程：每 **16学时** = 1 学分
  - 体育课：每 **32学时** = 1 学分
  - 单独设置的实验课：每 **20学时** = 1 学分
  - 集中实践教学环节（生产实习、课程设计、毕业论文/设计等）：每 **1周** = 1 学分

- [x] 挂科/不及格的处理及警示：
  - 必修课考核不及格 → 下学期初免费补考（最高70分）
  - 补考仍不及格 → 必须重修，按学分收费
  - "旷考"（未经请假擅自缺考）→ 以零分计算绩点，不得参加补考
  - 考试违纪/作弊 → 成绩以"无效"登记，以零分计算绩点，不得参加补考，并给予纪律处分
  - 缺课累计超过学时数1/3或作业缺交超1/3 → 无考核资格，成绩以"无资格"登记，以零分计算绩点

- [x] 学业预警制度：
  - 预警条件（退学警告）：
    - 一年级结束，累计取得学分不足本专业人才培养方案总学分的 **1/6**
    - 二年级结束，累计取得学分不足本专业人才培养方案总学分的 **1/3**
    - 三年级结束，累计取得学分不足本专业人才培养方案总学分的 **1/2**
  - 预警后措施：
    - 受退学警告者应转入下年级学习
    - 累计两次退学警告 → 退学处理
    - 三年级结束必修课学分累计 **25学分以上**未取得者，原则上应转入下年级学习
    - 转下年级学习需在每学年开学后两周内提出申请

> 数据来源：《河海大学全日制普通本科生学籍管理办法》（河海校政〔2017〕113号）、《河海大学学生考试纪律及违纪处理实施细则》、教师申请本科生课程成绩更改流程 jwc.hhu.edu.cn/2026/0310/c3072a323461/page.htm

## 10.6 学籍管理

- [x] 学籍信息查询/修改申请：
  - 学籍信息查询：学信网 https://www.chsi.com.cn/
